# Sistema de la tienda: versiones

Aquí solo se publican las versiones del programa. **El código no está aquí.**

Cada versión, en [Releases](../../releases), trae:

- **`Instalar-SistemaTienda-x.y.z.exe`**: el instalador. Doble clic y queda
  instalado. Si ya estaba instalado, lo actualiza sin tocar los datos.
- **`SistemaTienda-x.y.z.actualizacion`**: para Ajustes > Actualizaciones >
  "Instalar desde un archivo". Va firmada: el programa rechaza una que haya
  sido modificada.
- **`ultima.json`**: el aviso que revisa cada tienda para saber si hay una
  versión nueva.

Las tiendas con internet ven las versiones nuevas en Ajustes > Actualizaciones
y deciden cuándo instalarlas.
